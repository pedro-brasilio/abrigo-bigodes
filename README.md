# Abrigo Bigodes

Página de adoção de gatos e cachorros para uma ONG de resgate animal.

## O que é

Site onde o público vê os animais disponíveis para adoção, entende o processo e encontra outras formas de ajudar.

## Funcionalidades

- Fichas dos animais: idade, porte, data de chegada, saúde e recado dos voluntários
- Filtros por espécie e idade (só CSS, com `:has()`)
- Selo para quem espera há mais tempo
- Formulário que abre a mensagem pronta no WhatsApp da ONG
- Passo a passo da adoção e requisitos
- Seções Finais felizes e Ajude (PIX com botão de copiar)
- Tema claro e escuro automático
- Responsivo (celular a desktop)

## Tecnologias

- HTML5, CSS3, JavaScript puro
- Google Fonts: Calistoga, Figtree, Gochi Hand

## Como executar

Abra o `index.html` no navegador ou use o Live Server do VS Code.

## Personalização

Nome, contatos, PIX, números e fotos são exemplos. O número do WhatsApp fica em `js/script.js`.
